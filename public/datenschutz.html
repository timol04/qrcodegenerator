Datenschutz

Kurz gesagt: QR Pro läuft in deinem Browser. Deine Eingaben (Links, Texte, Logos, CSV-Dateien) werden nicht an einen Server gesendet und nicht gespeichert.

Was im Browser gespeichert wird

Nur deine Einstellungen für Hell/Dunkel und Sprache sowie, falls du Pro freischaltest, dein Lizenzschlüssel im lokalen Speicher deines Browsers. Es gibt keine Cookies, keine Analyse und keine Werbung.

Hosting

Die Seite wird über GitHub Pages ausgeliefert (GitHub, Inc., USA). Beim Aufruf kann GitHub technisch bedingt Daten wie deine IP-Adresse verarbeiten. Siehe die Datenschutzerklärung von GitHub.

Schriften und Bibliotheken

Schrift und Bibliotheken werden von dieser Seite selbst geladen, nicht von Drittanbietern.

Kauf von Pro

Falls Pro angeboten wird, läuft der Kauf über einen externen Zahlungsanbieter (Lemon Squeezy, der den Verkauf als Händler abwickelt). Dieser verarbeitet deine Zahlungs- und Kontaktdaten nach seiner eigenen Datenschutzerklärung. Zur Prüfung deines Lizenzschlüssels wird dieser an den Anbieter gesendet.
